# Imagens dos casos

Esta é a pasta única de imagens de todos os casos do site.

Padrão de nomes:
- `<slug-do-caso>-capa.webp` — imagem de capa.
- `<slug-do-caso>-hq.webp` — imagem inserida antes da seção definida no artigo.

Exemplo Jeffrey Dahmer:
- `jeffrey-dahmer-capa.webp`
- `jeffrey-dahmer-hq.webp`

Cada novo caso usa a mesma pasta. Não é necessário criar uma pasta nova por caso.
